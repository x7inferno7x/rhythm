# Безопасность и приватность

Ритм предназначен для одного пользователя на доверенном Mac. Локальная обработка снижает объём передачи данных внешним AI-сервисам, но не является защитой от вредоносного ПО с доступом к этой учётной записи macOS.

## Секреты

Пароль приложения Gmail и API-токен Strive хранятся в Связке ключей macOS. Swift-помощники передают значения через stdin/stdout локального процесса; они не включаются в аргументы команд, модельные запросы и историю чата. Сохранение выполняется после проверки подключения.

CalDAV credentials управляются n8n. Его Docker volume содержит чувствительные данные и не предназначен для публикации или обмена.

## Доступ к источникам

- Strive использует разрешённые GET-маршруты, без изменения задач.
- Gmail открывает Входящие read-only и читает BODY.PEEK, без установки Seen. Отправка, удаление и изменение меток не реализованы.
- У пароля приложения Gmail могут быть более широкие права, чем использует код. Режим чтения обеспечивается реализацией, а не отдельным узким OAuth scope.
- Содержимое писем может включать чувствительные сведения. Готовые выжимки и планы сохраняются на диске локально; специального шифрования истории поверх защиты macOS нет.
- Тело письма ограничено; MIME-вложения не анализируются и внешние ресурсы не загружаются. Ограниченный IMAP-фрагмент может содержать часть закодированного MIME-содержимого.

## Локальные порты

Интерфейс слушает `127.0.0.1:8787`, n8n публикуется на `127.0.0.1:5678`. Проверки Host, Origin, специального заголовка и CSP уменьшают поверхность атак через браузер. Markdown очищается DOMPurify.

Ollama во время работы слушает `0.0.0.0:11434` для доступа из Docker. Её API не требует аутентификации. Не открывайте этот порт в интернет; ограничьте доступ средствами firewall/сетевой конфигурации. Проект не предоставляет многопользовательскую авторизацию и не должен разворачиваться как публичный web-сервис без переработки.

## Недоверенные данные

Письма, события и задачи считаются данными, а не инструкциями. Запросы к модели явно запрещают исполнять команды из писем. У модуля почтовых выжимок нет инструментов для действий в аккаунтах. Однако качество текста и устойчивость самой модели к prompt injection не гарантированы: факты, сроки и предложения следует проверять по источникам.

## Что нельзя коммитить

`runtime/`, `diagnostics/`, Docker volumes, workflow exports с credentials, `.env`, логи, базы, приватные скриншоты и веса модели. `.gitignore` — дополнительная защита, а не замена проверке состава коммита.

При обнаружении утечки секрета отзовите его в исходном сервисе. Удаление файла из последнего коммита не убирает секрет из истории Git.

Не публикуйте реальные письма и ключи в Issues. Для обсуждения ошибки используйте обезличенный пример и название операции.
