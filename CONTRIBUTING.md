# Разработка

Для проверки логики достаточно Python 3.10+ и стандартной библиотеки:

```sh
python3 -m unittest discover -s tests -v
python3 -m compileall -q -x 'runtime|diagnostics' .
```

Тесты интеграций используют подменённые ответы; доступ к реальным аккаунтам и модель не нужны. GUI и Swift-сборка требуют macOS. Полный сценарий дополнительно требует собственных Ollama, Docker Desktop, n8n и CalDAV.

При изменении интеграций сохраняйте режим чтения, ограниченный размер контекста, проверку TLS и отсутствие секретов в логах. Контрольная точка почты должна двигаться только после сохранения отчёта. Ошибки источников нельзя подменять сообщением об отсутствии новых данных.

Используйте синтетические задачи, письма и события в тестах. Не добавляйте runtime и приватные диагностические экспорты. При изменении workflow проверяйте и чат, и ежедневный план.

В описании изменения указывайте конкретное поведение до и после, способ проверки и оставшиеся ограничения. Вопросы по правам использования собственного кода решаются с владельцем репозитория; лицензии сторонних библиотек перечислены отдельно.
